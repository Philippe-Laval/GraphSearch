# ITSM Corpus

## Terms

Added a comprehensive set of ITSM terms and relations aligned with ITIL best practices, then verified the build succeeds.

Terms (~100) cover:
-	Core entities: incident, problem, change, service request, known error, workaround
-	Configuration: CI, CMDB, asset, service catalog/portfolio
-	Roles: service desk, assignment group, change/problem/incident manager, CAB
-	Workflow: priority, impact, urgency, severity, resolution code, escalation
-	SLA/OLA/UC, KPI, MTTR, MTBF, breach
-	Change types: standard/normal/emergency, maintenance window, rollback plan
-	Release, availability, capacity, continuity, DR
-	Knowledge base, frameworks (ITIL, COBIT, ISO 20000)

## Relations

Relations (~70) cover 
- causal (caused by, resolves), 
- assignment (assigned to, escalated to, approved by), 
- CMDB topology (part of, hosted on, depends on, runs on), 
- impact (affects, impacted by), 
- change lifecycle (implements, superseded by), 
- knowledge (documented in) and 
- SLA governance (governed by, breached by).
