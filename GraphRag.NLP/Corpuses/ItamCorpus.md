# ITAM Corpus

## Terms

Added ITAM terms and relations aligned with SAM/HAM and ISO 19770 best practices. Build passes.

Terms cover:
-	Asset types: hardware, software, cloud, virtual, consumables
-	Hardware: endpoints, servers, network/storage devices, IoT
-	Software: applications, OS, middleware, SaaS, patches
-	Licensing: entitlement, perpetual/term/concurrent/named-user/per-core, ELP, true-up, compliance/audit
-	Lifecycle: procurement → deployment → in-use → retired → disposed (EOL/EOS)
-	Financial: TCO, CapEx/OpEx, depreciation, chargeback
-	Vendors, contracts, warranty, renewals
-	Identification: asset tag, serial, MAC, product key, SKU
-	Repository: asset register, CMDB, discovery, reconciliation, normalization
-	Governance: ITAM, SAM, HAM, ISO 19770, ITIL

## Relations

Relations cover :
- ownership (owned by, assigned to, custodian of), 
- location, composition (installed on, hosted on), 
- licensing (licensed to, consumes license, harvested from, over-licensed), 
- procurement (purchased from, published by), 
- contracts (under warranty, expires on), 
- lifecycle transitions (retired on, replaced by), 
- financial (depreciated over, charged to), 
- discovery (discovered by, reconciled with).
